Job Mailer Settings

Sender & sending limits

Each email waits a random time between min and max, and sending pauses when the daily limit is reached and continues the next day by itself. A personal Gmail account allows roughly 500 emails a day; sending many identical emails quickly can get an account flagged, so keep these conservative. Daily limit 0 = no limit.

Email templates

The first template is the default. In a JSON list, "template": "name" picks another one. Variables: {{company}} {{name}} {{email}} and any field from your JSON (for example {{hrName}}). Use {{hrName|Hiring Team}} to give a fallback.

CVs (PDF)

The first CV is the default. In a JSON list, "cv": "name" picks another one and "cv": "none" sends no attachment.

Follow-ups

Sent in the same Gmail thread as Re: original subject, without the CV. Variables: {{company}} {{name}} {{days}} {{originalSubject}}. Max 0 turns follow-ups off.
